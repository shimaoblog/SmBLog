# 图片灯箱效果(Minima)
```html
<style>
.image-lightbox {
  position: fixed;
  inset: 0;
  background: rgba(0,0,0,0.75);
  z-index: 9999;
  display: flex;
  align-items: center;
  justify-content: center;
  padding: 20px;
  box-sizing: border-box;
  opacity: 0;
  pointer-events: none;
  transition: opacity 0.24s ease;
}
.image-lightbox.active {
  opacity: 1;
  pointer-events: auto;
}

.lightbox-wrap {
  max-width: 90%;
  max-height: 90vh;
  text-align: center;
  transform: scale(0.94);
  transition: transform 0.24s ease;
}
.image-lightbox.active .lightbox-wrap {
  transform: scale(1);
}

.lightbox-img {
  max-width: 100%;
  max-height: 80vh;
  border-radius: 4px;
}

.lightbox-desc {
  color: #ffffff;
  margin-top: 12px;
  font-size: 14px;
  line-height: 1.6;
  word-break: break-all;
  opacity: 0;
  transform: translateY(6px);
  transition: opacity 0.2s ease 0.06s, transform 0.2s ease 0.06s;
}
.image-lightbox.active .lightbox-desc {
  opacity: 1;
  transform: translateY(0);
}
</style>

<div class="image-lightbox" id="globalLightbox">
  <div class="lightbox-wrap">
    <img class="lightbox-img" id="lightboxImg" alt="">
    <div class="lightbox-desc" id="lightboxDesc"></div>
  </div>
</div>

<script>
const lightbox = document.getElementById('globalLightbox');
const previewImg = document.getElementById('lightboxImg');
const descBox = document.getElementById('lightboxDesc');

document.querySelectorAll('img').forEach(img => {
  // 过滤页眉、页脚、图标，不会误触发
  if (img.closest('header, footer, .social-links, .avatar, .logo')) return;

  img.style.cursor = 'zoom-in';
  img.addEventListener('click', function () {
    previewImg.src = this.src;
    descBox.textContent = this.alt || '暂无图片描述';
    lightbox.classList.add('active');
  });
});

// 点击背景关闭
lightbox.addEventListener('click', e => {
  if (e.target === lightbox) {
    lightbox.classList.remove('active');
  }
});

// ESC按键关闭
document.addEventListener('keydown', e => {
  if (e.key === 'Escape') lightbox.classList.remove('active');
});
</script>
```

将这段代码放在footer.html里就可以工作了。

# 站点标题前加图标(Minima)


修改header.html中的标题行成这个样子
```html
<a class="site-title" rel="author" href="{{ "/" | relative_url }}">
  <img src="{{ '/assets/images/logo.svg' | relative_url }}" style="height:1.1em;vertical-align:middle;margin-right:6px;">
  {{ site.title | escape }}
</a>
```
*ps:图片自行更换。*

# Json订阅(Jekyll)

`Gemfile`中加入


```ruby
gem "jekyll-json-feed"
```

在`_config.yml`中加入


```yaml
- jekyll-json-feed
```

开启后，路径在`feed.json`

*ps:可能需要Action配置*
